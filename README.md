# ScheduleApp

**스프링부트를 활용한 일정 관리 앱 프로젝트 입니다.**

## 📌 주요 기능

- **일정 생성**: 일정을 생성합니다. 
- **일정 다건 조회**: 생성된 일정을 조회합니다.
- **일정 단건 조회**: 생성된 일정을 식별자를 통해 조회합니다.
- **일정 단건 수정**: 식별자를 통해 조회한 일정을 수정할 수 있습니다.
- **일정 단건 삭제**: 식별자를 통해 조회한 일정을 삭제할 수 있습니다.

## 🛠️ 설치 및 실행 방법

### 1. 클론하기
```bash
git clone https://github.com/thdwnsdlf61/ScheduleApp.git
cd ScheduleApp
```

### 2. 브랜치 변경
```bash
git checkout essential/level1
```

### 3. 의존성 설치
```bash
npm install
```

### 4. 개발 서버 실행
```bash
npm start
```

### 5. 웹 브라우저에서 열기
개발 서버가 실행된 후, 브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 애플리케이션을 확인하세요.
